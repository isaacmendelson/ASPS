# AIducation — ASPS AI Operating System

The team's **learning system**: how the AI OS captures, structures, and reuses knowledge so the team gets sharper over time instead of repeating mistakes.

## Subdirectories

| Folder | Holds |
|---|---|
| [principles/](principles/) | Foundational, cross-role principles — the always-true baseline |
| [lessons/](lessons/) | Lessons learned — what went wrong/right and the takeaway |
| [prompts/](prompts/) | Reusable prompt templates |
| [schemas/](schemas/) | Structured formats (YAML) for the above |
| [role-training/](role-training/) | Per-role training material, updated as lessons accumulate |
| [learning-engine/](learning-engine/) | Integration point for the Knowledge Engine (Principle 7) |

## Principle
Content is **reusable and structured**. Every lesson, prompt, and role note should
follow a schema so it can be indexed, retrieved, and fed back to agents.
