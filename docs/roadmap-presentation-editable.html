05 · Gap Analysis

ניתוח פערים

דברים שצריך להחליט עליהם לפני שזו תכנית עבודה

🔴 פריטים לא מסווגים

  • תשתיות חיוב לקוחות — קריטי. בלי זה אין הכנסות. Now או Angel?
  • השלמת TrackUrlAlert — כנראה Now? כבר בפיתוח
  • ניהול Tracked URLs — קשור ל-TrackUrlAlert
  • הפצת דומיין מסוכן בין לקוחות — Network Effect חזק!
  • Data Collaboration Manager — לא מוגדר
  • שיווק, B2B, NPO — תפקידים? תקציב? מתי?

🟠 ערבוב קטגוריות

  • ISO + SOC2 + GDPR = תהליכים של חודשים עם יועצים, לא פיצ'רים
  • B2B Manager / NPO Manager = תפקידים, לא בניית פיצ'ר
  • Education Center / Community = יצירת תוכן מתמשכת
  • "Android בסיסי" מול "מושלם" — מה ההבדל?

🔵 תלויות נסתרות

  • Keycloak (Angel) מול Auth CURVE קיים — שילוב או החלפה?
  • Protective Actions תלוי בהעדפות לקוח
  • iOS רק ב-VC — בישראל זה 40% מהשוק
  • Load Tests רק ב-VC — אבל Angel מדבר על "מאות אלפי משתמשים"

🟣 חסר בתמונה

  • מודל עסקי ותמחור — Subscription? Freemium? B2B?
  • Hiring Plan — כמה מפתחים? מתי? איזה roles?
  • Runway — כמה חודשים עד VC? כמה כסף נצרך?
  • KPIs — מה מגדיר הצלחה בכל שלב?
  • איך מגיעים ללקוחות ראשונים?

07 · Why Angel?

בשביל מה צריך Angel?

4 יעדים מרכזיים שהגיוס מאפשר
🚀

השלמת פיתוח מהירה

לוח זמנים קצר ביותר אפשרי כדי לזכות בראשוניות בשוק. Android מושלם, WhatsApp, הסלמה משודרגת, שפות נוספות.

🔐

אבטחת מידע ותקנים

היערכות לרמת ביטחון מידע ועמידה בתקנים ורגולציה ברמות הגבוהות ביותר. ISO-27001, SOC 2, GDPR, CCPA, Pentest.

☁️

תשתיות Production

הפעלה חלקה תוך גידול מהיר לסדרי גודל של מאות אלפי משתמשים בתוך חודשים ספורים. Pipeline, QA, Cloud, Automation.

⚖️

תשתית משפטית וביטוחית

הגנה משפטית וביטוחית שמאפשרת פעילות מסחרית ללא סיכון. תנאי שימוש, פרטיות, רגולציה.

פריט חדש

📁

קטגוריה חדשה

💡 הקטגוריה תופיע בשקף שתבחרו, ותהיה זמינה לבחירה כשמוסיפים פריטים חדשים.
📊

שקף חדש

💡 שקפים חדשים נוצרים ריקים. אחרי יצירה, ניתן להוסיף קטגוריות אליהם דרך כפתור "+ הוסף קטגוריה לשקף זה" שמופיע בתחתית כל שקף.
