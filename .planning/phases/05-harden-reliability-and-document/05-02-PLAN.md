  <action>
**In MessageQueueService.js:**

1. Add `async persist()` method:
   ```javascript
   /**
    * Persist queue to chrome.storage.session (survives SW termination)
    */
   async persist() {
     try {
       const data = this.queue.map(item => ({
         message: item.message,
         timestamp: item.timestamp,
         priority: item.priority
       }));
       await chrome.storage.session.set({ messageQueue: data });
       console.log(`[MessageQueue] Persisted ${data.length} messages to storage.session`);
     } catch (e) {
       console.error('[MessageQueue] Error persisting queue:', e);
     }
   }
   ```

2. Add `async restore()` method:
   ```javascript
   /**
    * Restore queue from chrome.storage.session (after SW restart)
    */
   async restore() {
     try {
       const data = await chrome.storage.session.get('messageQueue');
       if (data.messageQueue && Array.isArray(data.messageQueue)) {
         // Filter out expired messages during restore
         const now = Date.now();
         this.queue = data.messageQueue.filter(item => {
           const age = now - item.timestamp;
           return age < this.ttlMs;
         });
         console.log(`[MessageQueue] Restored ${this.queue.length} messages from storage.session`);
       }
       // Clear storage after restore (will be re-persisted on next enqueue)
       await chrome.storage.session.remove('messageQueue');
     } catch (e) {
       console.error('[MessageQueue] Error restoring queue:', e);
     }
   }
   ```

3. In `enqueue()`, call `this.persist()` at the end (after the push and size limit enforcement):
   ```javascript
   // Persist after modification (fire-and-forget, don't block enqueue)
   this.persist();
   ```

4. In `flush()`, clear persisted data after flush:
   ```javascript
   // Clear persisted data after flush
   chrome.storage.session.remove('messageQueue').catch(() => {});
   ```

5. In `clear()`, also clear persisted data:
   ```javascript
   chrome.storage.session.remove('messageQueue').catch(() => {});
   ```

**In background.js:**

1. In `init()`, BEFORE `await connectionService.connect()`, add queue restore:

2. Add `import { messageQueueService } from './services/MessageQueueService.js';` at the top (check if already imported -- it may not be directly imported in background.js since ConnectionService imports it internally).

Note: `chrome.storage.session` was chosen over `chrome.storage.local` because session data is automatically cleared when the browser is closed. This prevents stale queued messages from accumulating across browser sessions. The session storage quota (10MB) is more than sufficient for up to 100 small JSON messages.
