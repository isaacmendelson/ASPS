# ASPS - מערכת הגנה מפני הונאות

**גרסה:** 0.0.0.3  
**תאריך שחרור:** 26 במרץ 2026

---

## סקירה כללית

ASPS היא מערכת הגנה מקיפה מפני הונאות שמנטרת פעילות משתמשים ומגינה מפני הונאות מקוונות, פישינג וניסיונות הונאה.

### רכיבים
- **Backend** - שרת .NET 8 עם ניתוח בזמן אמת
- **WebApi** - לוח בקרה למנהלים ונקודות קצה API
- **Agent** - אפליקציית שולחן עבודה ל-Windows
- **Extension** - תוסף לדפדפן Chrome

## גרסה 0.0.0.3 - הערות שחרור

### 🆕 תכונות חדשות

#### שכבת המשתמש (ASPS-258)
- **UserRiskProfile** - ציון סיכון בזמן אמת לכל משתמש
- **חישוב ציון סיכון** - נוסחה משוקללת עם דעיכה בזמן
- **זיהוי יירוט OTP** - מזהה כאשר נוכלים מיירטים קודי אימות דו-שלבי
- **מסך שחור** - מסתיר מידע רגיש כאשר מזוהה גישה מרחוק באתרי בנקים
- **התראת משתמש ממוקד** - מתריע כאשר משתמש מופיע ברשימות הונאה ברשת האפלה
- **אירוע SetTrackedDomains** - סנכרון דומיינים חוצה פלטפורמות
- **מטריצת פעולות הגנה** - מערכת תגובה מבוססת סיכון (אזהרה/חסימה/נעילה)
- **הגדרת אתרים רגישים** - רשימה ניתנת להגדרה של דומיינים רגישים

#### שכבת המכשיר (ASPS-374)
- שיפורי **TrackUrlAnalyzer** (זיהוי פיתיון, זיהוי טפסים, אינדיקטורי דחיפות)
- **זיהוי קטגוריית אתר** - מסווג אתרים לפי סוג (בנקאות, קריפטו, וכו')
- **לוגיקת זיהוי פישינג** - דמיון דומיין, בדיקות SSL, ניתוח תוכן

#### תוסף הדפדפן
- **FormMonitorService** - מזהה ועוקב אחר שליחות טפסים
- **באנר אזהרה** - אזהרה לא חוסמת לאתרים חשודים
- **דף חסימה** - חסימת דף מלאה לאתרים בסיכון גבוה
- **TrackUrlAlert** - מימוש מלא

#### לוח בקרה למנהלים
- **סימולציות** - סימולטור התראות מכשיר עם השלמה אוטומטית
- **מספרי טלפון ברשימה שחורה** - דף ניהול למספרים חסומים
- **אתרי בנקים** - דף ניהול לדומיינים רגישים של בנקים
- **אתרי פישינג ידועים** - שיפורים בדף הניהול

#### סוכן שולחן העבודה
- **התראות Toast של Windows** - התראות מבוססות סיכון עם פעולות
- **מתקין** - מתקין Inno Setup מוכן להפצה

### 🐛 תיקוני באגים

## התקנה

### Backend
```bash
cd ASPSBackend14_J
dotnet restore
dotnet build
dotnet run --project ASPSBackend
```

### WebApi
```bash
cd ASPSBackend14_J
dotnet run --project WebApi
```

### סוכן (Windows)
1. הורידו `AntiScamDesktop-Setup-0.0.0.3.exe`
2. הריצו את המתקין
3. עקבו אחר אשף ההתקנה

### תוסף (Chrome)
1. פתחו `chrome://extensions`
2. הפעילו מצב מפתח
3. טענו לא ארוז מתוך `apps/extension/chrome/`

## חישוב ציון סיכון

```
ציון_סיכון_סופי = min(100, (סיכון_בסיס + Σ גורמים_משוקללים) × דעיכת_זמן + איומים_פעילים)

כאשר:
- סיכון_בסיס = 0.3 × ציון_פגיעות + 0.4 × ציון_חשיפה
- גורמים משוקללים: URL_מסוכן(1.0), שיחה_חשודה(1.5), גישה_מרחוק(2.0), הונאה_בתהליך(3.0)
- דעיכת_זמן = 0.95^ימים
```

### פעולות הגנה לפי ציון סיכון

| ציון סיכון | פעולות |
|------------|--------|
| 0-20 | ניטור בלבד |
| 21-40 | באנר אזהרה |
| 41-60 | אזהרה מודאלית + התראת Push |
| 61-80 | חסימת דף + התראת SMS |
| 81-100 | נעילה מלאה + איש קשר חירום |
