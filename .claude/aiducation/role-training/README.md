# AIducation — Role Training

Per-role training material: the knowledge each agent needs to do its job well, beyond its
charter in `.claude/agents/`. (Replaces the earlier `roles/`.)

The Knowledge Manager updates role training as lessons accumulate — this is how a completed
task feeds back into the agents that will face similar work next time (Principle 6).

Suggested layout: one file per role, e.g. `backend.md`, `qa.md`, matching the agent names.
