<objective>
Implement device registration and token acquisition so the Desktop App obtains a valid token from Backend before sending URL alerts.

Purpose: The Backend's TokenStore starts empty on each restart. The current hardcoded UUID token ("12345678-1234-1234-1234-123456789012") is NEVER registered, causing every URL alert to be rejected with "InvalidToken". Without a real token, the entire pipeline is dead at the Backend door. This plan fixes the critical authentication blocker identified in Phase 3 research.

Output: Modified Desktop App that sends a RegisterDevice message at startup, receives and persists a real token, and uses it for all subsequent URL alerts.
</objective>

2. In `auth_manager.py`, rewrite `authenticate()` to actually acquire a token from Backend:
   ```python
   def authenticate(self) -> bool:
       """
       Authenticate with backend by requesting a token via ZMQ RegisterDevice.
       Returns True if successful.
       """
       print("\n" + "#" * 60)
       print("[AUTH] AUTHENTICATING (ZMQ RegisterDevice)")
       print("#" * 60)

       # Try to request token from Backend
       result = self.zmq_client.request_token(
           device_uid=self.device_info.get('id', 'PC-JOHN-001'),
           email=self.email,
           mac=self.device_info.get('MAC', '00:11:22:33:44:55')
       )

       if result and result.get('token'):
           self.token = result['token']
           self.is_authorized = True

           # Parse expiration
           exp_str = result.get('expiration')
           if exp_str:
               try:
                   # Handle ISO format with or without Z suffix
                   exp_str = exp_str.replace('Z', '+00:00')
                   from datetime import timezone
                   self.expires_at = datetime.fromisoformat(exp_str).replace(tzinfo=None)
               except (ValueError, TypeError):
                   # Default: 24 hours from now
                   self.expires_at = datetime.now() + timedelta(hours=24)
           else:
               self.expires_at = datetime.now() + timedelta(hours=24)

           self._save_token()
           print(f"[AUTH] SUCCESS: Got token: {self.token[:30]}...")
           print(f"[AUTH] Expires: {self.expires_at}")
           print("#" * 60 + "\n")
           return True
       else:
           # Fallback: continue without token (alerts will fail but app runs)
           print("[AUTH] WARNING: Could not get token from Backend")
           print("[AUTH] URL alerts will be rejected until token is acquired")
           self.token = ""
           self.is_authorized = False
           print("#" * 60 + "\n")
           return False
   ```

   Also update `is_valid()` to actually check token validity instead of always returning True:

   def is_valid(self) -> bool:

       if not self.token:

       if self.is_expired():
           return False
       return True
   ```

   Update `ensure_authenticated()` -- it already calls `is_valid()` and falls back to `authenticate()`, so no changes needed there. But add a note:

   def ensure_authenticated(self) -> bool:

       Ensure we have a valid token.
       If saved token is valid, use it. Otherwise, request new from Backend.
       """

           return True

       print("[AUTH] Token invalid or expired, requesting from Backend...")
       return self.authenticate()
   ```
