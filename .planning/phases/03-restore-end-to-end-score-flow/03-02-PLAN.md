  <what-built>
  Complete end-to-end score flow pipeline: Chrome Extension submits URL via WebSocket to Desktop App, which forwards to Backend via ZMQ with a real token (from RegisterDevice). Backend analyzes URL and publishes result via ZMQ PUB/SUB. Desktop App receives notification and broadcasts score to Extension via WebSocket. Extension displays score in popup and updates badge icon.
  </what-built>
  <how-to-verify>
  **Prerequisites (start these services):**
  1. Start the C# Backend: `cd ASPSBackend14_J/ASPSBackend && dotnet run`
     - Wait for "RealTimeAlertListener started on port 50001" in console
  2. Start the Desktop App: `cd apps/desktop/win/src && python main.py`
     - Watch for "[AUTH] SUCCESS: Got token: ..." in console (confirms token acquisition)
     - If you see "[AUTH] WARNING: Could not get token from Backend", check:
       a. Is Backend running?
       b. Does the USER_EMAIL in config.py match an active user in the database?
       c. Check Backend console for error messages
  3. Load Chrome Extension (if not already loaded):
     - chrome://extensions -> Load unpacked -> select `apps/extension/chrome/`
  4. Clear Extension cache: Open Extension popup -> click settings gear -> "Clear Cache"
  5. Delete Desktop App cache: Delete `%APPDATA%\AntiScam\cache.json` if it exists

  **Test Steps:**
  1. Open a NEW tab and navigate to `https://example.com` (simple, known URL)
  2. Watch Desktop App console for:
     - `[ZMQ-CLIENT] >>> UrlAlert to port 50001` (URL sent to Backend with real token)
     - `[ZMQ-CLIENT] <<< Response from Backend` with `{"success": true}` (Backend accepted)
     - `[NOTIFICATION] RECEIVED FROM SERVER!` (analysis result came back)
     - `[NOTIFICATION] Broadcasted result to extension: score=XX` (sent to Extension)
  3. Watch Backend console for:
     - Token validation passing (no "InvalidToken" error)
     - Analysis starting for the URL
     - Notification published
  4. Check the Chrome Extension popup:
     - Click the Extension icon
     - Should show a numeric score (not "--" or "Checking...")
     - Badge on Extension icon should have a color (green=safe, yellow=warning, red=danger)
  5. Timing: The full round-trip (from navigation to score displayed) should complete in under 10 seconds

  **If something fails, note:**
  - Which step failed
  - What error messages appear in Desktop App console, Backend console, or Extension console (F12 -> Console)
  - Exact text of any error responses
  </how-to-verify>
