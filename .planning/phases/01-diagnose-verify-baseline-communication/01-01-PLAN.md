    **Step 2: Create standalone ZMQ REQ/REP diagnostic script**

    Create `apps/desktop/win/src/diag_zmq_test.py` -- a self-contained diagnostic script that:

    1. Defines a `diag_log(component, direction, message, data=None)` function that prints ISO-8601 UTC timestamps with `>>>` for SEND and `<<<` for RECV, plus optional JSON data indented.

    2. **Port verification** (function `verify_ports()`):
       - Uses `subprocess.run()` to execute: `powershell -Command "Get-NetTCPConnection -State Listen | Where-Object {$_.LocalPort -in @(50001, 50002, 5555, 5556)} | Select-Object LocalAddress, LocalPort, OwningProcess | ConvertTo-Json"`
       - Parses the JSON output to check which of the 4 ports are listening.
       - Prints a clear PASS/FAIL for each port.
       - Returns a dict of `{port: bool}` results.
       - If port 50001 is not listening, prints: "FATAL: Port 50001 not listening. Start the Backend (ASPSBackend) first." and returns early.

    3. **ZMQ REQ/REP round-trip test** (function `test_zmq_reqrep()`):
       - Creates `zmq.Context()` and `zmq.REQ` socket.
       - Sets `RCVTIMEO=5000`, `LINGER=0`, `SNDTIMEO=5000`.
       - Connects to `tcp://127.0.0.1:50001`.
       - Sends a `RequestToken` message: `{"MessageType": "RequestToken", "DeviceUid": "PC-DIAG-TEST-001"}`.
       - Logs the SEND with timestamp and full JSON payload.
       - Waits for response with try/except for `zmq.Again` (timeout).
       - On success: logs the RECV with timestamp and response JSON. Prints "PASS: ZMQ REQ/REP round-trip works. Response received."
       - On timeout: prints "FAIL: ZMQ REQ/REP timed out after 5s. Possible causes: (1) CurveMQ still enabled, (2) Backend not running, (3) Port 50001 not accepting connections."
       - On any other exception: prints the error with traceback.
       - Always closes socket and terminates context in a finally block.
       - Returns True/False for success/failure.

    4. **Main block** (`if __name__ == "__main__"`):
       - Prints a header: `"=== ASPS Phase 1 Diagnostic: ZMQ REQ/REP Test ==="`
       - Calls `verify_ports()`. If port 50001 not listening, exit with code 1.
       - Calls `test_zmq_reqrep()`. Exit with code 0 on success, 1 on failure.
       - Prints a summary footer: `"=== Diagnostic Complete ==="` with overall PASS/FAIL.

    The script should have NO dependencies beyond `zmq`, `json`, `subprocess`, `datetime`, `sys`, `traceback` (all already available in the project's Python environment).
