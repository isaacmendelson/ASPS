11AnyDesk direction=unknown fixהיום
שלושה תיקונים:
  • Unified backfill — אוסף events מ-ad.trace + ad_svc.trace + connection_trace.txt, ממיין לפי timestamp, מריץ דרך ה-tracker לפני start של tail threads.

12Faster RemoteAccessAlert delivery on app/session closeהיום
close_debounce: 3s → 1s. session_end_debounce: 10s → 4s. Adaptive interval: 1s pending / 5s active / 30s idle. AnyDesk close → alert תוך ≤ 2s (במקום 8-13s).

14CenteredToast — חלון התראה מותאםהיום

  • borderless, always-on-top (lift loop כל 2s), ממורכז.
  • Drag-and-drop (bind על Toplevel + הגבלה ל-header zone).
  • מצב locked (אין close, persistent — ל-active danger) ו-cleared (ירוק, יש Close — ל-cleared).
  • Singleton — transform_to_cleared משנה את הקיים בלי ליצור חדש.
15DangerDetailsWindow — View Details בתוך ה-agentהיום

16DangerMode — fast polling + no debounceהיום
singleton services/danger_mode.py. ImmediateDangerNotification → activate() (poll כל 2s + bypass debounce). ImmediateDangerEndedNotification → deactivate(). AnyDesk close בזמן danger → alert תוך ≤ 2s.
