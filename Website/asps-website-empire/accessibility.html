Accessibility Statement

Our commitment to digital accessibility for everyone.

Last Updated: February 26, 2026

Our Commitment

ASPS (Anti-Scam Protection Systems) is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply relevant accessibility standards.

Conformance Status

We strive to conform to the following accessibility standards:

  • WCAG 2.1 Level AA Web Content Accessibility Guidelines
  • Israeli Standard IS 5568 Israel's web accessibility standard, aligned with WCAG 2.1
♿ Compliance Level: WCAG 2.1 AA (Israeli Standard 5568)

Accessibility Features

This website includes the following accessibility features:

  • Keyboard navigation All interactive elements are accessible via keyboard
  • Skip navigation link Jump directly to main content
  • Focus indicators Visible focus outlines on all interactive elements
  • Semantic HTML Proper heading hierarchy and ARIA landmarks
  • Alt text Descriptive alternative text for meaningful images
  • Reduced motion Respects user preferences for reduced animations
  • Form labels All form inputs have associated labels
  • Color contrast Text meets WCAG AA contrast requirements
  • Responsive design Works across devices and screen sizes

Technologies Used

This website relies on the following technologies:

  • HTML5
  • CSS3
  • JavaScript (Vanilla)
  • WAI-ARIA

Known Limitations

While we strive for full accessibility, some limitations may exist:

  • Some decorative canvas animations are not accessible to screen readers (they are marked as decorative)
  • Third-party content (external links) may not meet our accessibility standards

We are continuously working to identify and resolve accessibility issues.

Feedback

We welcome your feedback on the accessibility of our website. If you encounter accessibility barriers or have suggestions for improvement, please contact us:

  • Email: info@asps.io
  • Subject line: Accessibility Feedback

We aim to respond to accessibility feedback within 5 business days.

Assessment Approach

ASPS assesses the accessibility of this website through:

  • Self-evaluation using automated accessibility tools
  • Manual testing with keyboard navigation
  • Screen reader testing
  • Ongoing monitoring and updates

הצהרת נגישות

ASPS (מערכות הגנה מפני הונאות) מחויבת להנגשת האתר לאנשים עם מוגבלויות. אנו פועלים לשפר את חוויית המשתמש לכולם ומיישמים תקני נגישות רלוונטיים.

רמת התאמה:

  • WCAG 2.1 רמה AA
  • תקן ישראלי 5568 (IS 5568)

תכונות נגישות באתר:

  • ניווט באמצעות מקלדת
  • קישור לדילוג לתוכן הראשי
  • מחווני פוקוס גלויים
  • היררכיית כותרות נכונה
  • טקסט חלופי לתמונות
  • תמיכה בהעדפת הפחתת תנועה
  • ניגודיות צבעים תקנית

יצירת קשר בנושא נגישות:

נשמח לשמוע מכם אם נתקלתם בבעיית נגישות או אם יש לכם הצעות לשיפור.

  • אימייל: info@asps.io

אנו מתחייבים להשיב לפניות נגישות תוך 5 ימי עסקים.
