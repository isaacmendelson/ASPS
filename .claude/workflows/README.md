# Workflows — ASPS AI Operating System

Repeatable, multi-role process definitions. Each workflow describes **how a class of work moves through the team** — the roles involved, the sequence of steps, the hand-offs, and the gates.

A workflow is a *process template*, not a one-off plan. It answers: who does what, in what order, and what "done" looks like at each stage.
