# ⚠️ ASPS Security Audit — Issues Requiring Attention

**Latest audit:** 2026-05-03
**Full report:** [2026-05-03.md](2026-05-03.md)

## Critical findings (action within 7 days)

1. **TypeNameHandling.Auto RCE chain** — 60+ sites in `CQRSGateway.cs` + `CQRSClient.cs` allow remote code execution via JSON `$type` injection on ZMQ ports 5555/5556 (which are bound to all interfaces, not localhost).
2. **Hardcoded admin allow-list** — `AdminClaimsTransformer.AdminUsernames = { "asps-admin", "isaac", "admin" }` grants Admin to anyone with that Keycloak login name.
3. **Dev-mode login → Admin** — `Login.cshtml.cs:50-92` accepts any username (no password) when Keycloak is unconfigured.
4. **Keycloak ClientSecret committed** — `WebApi/appsettings.Docker.json:12` (committed `450b7a9`, not gitignored).
5. **MySQL root password committed** — `docker-compose.yml:13,22,48` (`zappa22`); same password reused for JIRA admin (`isaac`).

## High-severity findings (action within 30 days)

- API controllers (Users, UserDevices, Alerts, Simulations, Version) are **anonymous** — only SystemController has `[Authorize]`.
- `RequireHttpsMetadata = false` hardcoded in `Program.cs:93`.
- `/DebugClaims` is `[AllowAnonymous]` and dumps every claim.
- `DeviceLogin` page logs full token in plaintext on every device registration.
- No payload size limit / `MaxDepth` / `MaxRequestBodySize` anywhere → DoS.
- Browser extension `<all_urls>` permission + raw browser history scraping (privacy posture).
- No installer code-signing, no auto-update channel.
- Possible Google `client_secret` hardcoded in shipped Python binary.
- Mobile spec underspecifies Android Accessibility Service / SMS / key escrow.
- CURVE keys unprotected on Windows; no rotation.
- DB connection uses `root` user.
- Cleanup commit reverted within 8 days; no CI guardrail.
- Roadmap Viewer export uses `UnsafeRelaxedJsonEscaping` → stored XSS in exported HTML.

## Top 11 actions for the next sprint (in order)

1. Rotate MySQL root, both Keycloak ClientSecrets, JIRA `isaac` password.
2. Remove `AdminClaimsTransformer.AdminUsernames` and the duplicate in `Program.cs:132-134`.
3. Remove or hard-gate `Login.OnPostAsync` dev-mode admin grant.
4. Replace `TypeNameHandling.Auto` with `None` (or strict binder) in CQRSGateway/CQRSClient.
5. Bind ZMQ ports 5555/5556 to `tcp://127.0.0.1:`.
6. Run `git filter-repo` to scrub history; force-push; have all developers re-clone.
7. Add `[Authorize(Roles="Admin")]` to every controller; `[Authorize]` on NotificationsHub.
8. Set `RequireHttpsMetadata = true`.
9. Remove `[AllowAnonymous]` from `/DebugClaims`.
10. Stop logging full request/response bodies in `DeviceLogin.cshtml.cs`.
11. Add `gitleaks` (or `trufflehog`) as pre-commit hook + GitHub Actions required check.
